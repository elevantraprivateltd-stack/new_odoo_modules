Module Overview

The School Management Contact Fields module seamlessly extends the res.partner and crm.lead models in Odoo 19. It introduces custom school-related tracking fields—such as Zone, Area, and Board Type—positioned directly below address blocks for efficient data entry and contact categorization.

Key Features

Tailored fields and view integrations for educational institutions and CRM workflows.

Custom Address Fields

Seamlessly places fields like Zone, Area, and Board Type right below the standard address block in the Contacts form.

CRM View Integration

Extends CRM Lead forms to reflect school and regional data directly, ensuring full visibility during sales pipeline management.

School Management Ready

Designed specifically to record educational board types, campus zones, and regional areas for streamlined academic operations.

Clean UI Placement

Form views are modified precisely without cluttering the native Odoo user interface, keeping data entry smooth and intuitive.
