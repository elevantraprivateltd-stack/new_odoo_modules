Module Overview

The Sale Order Template & Engagement Letter module enhances Odoo 19 Sales management by adding custom quotation reporting capabilities and dedicated proposal tabs. It allows you to print proposal text directly from terms & conditions and generate professional Engagement Letters with dedicated print actions.

Key Features

Streamline sales proposals and formal client engagement reporting.

Custom Proposal Printing

Print custom proposal text directly in sale order reports populated straight from terms and conditions fields.

Engagement Letter Generation

Includes a dedicated print button and custom report layout designed specifically for formal client Engagement Letters.

Dedicated Engagement Page

Adds a custom page to the Sale Order notebook interface to store engagement details and contract conditions neatly.

Optimized UI Workflow

Enhances standard sale order views for effortless template selection, faster proposal editing, and smooth report exports.
