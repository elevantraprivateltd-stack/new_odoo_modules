Overview

This module adds a reporting wizard and per-account print actions for Analytic Accounts. Filter by date range, analytic plan, specific accounts, company, and posted vs. all entries — then generate a formatted PDF statement or an Excel workbook, grouped and totaled per account, ready to send or file.

What's included
📅
Multi-criteria filtering
Date From / Date To, one or more Analytic Plans, one or more Analytic Accounts, Company, and Posted-only or All entries — combine any of them.
📄
PDF statements
Each account prints as its own grouped, totaled section — clean enough to send straight to a client or file for audit.
📊
Excel export
The same grouped data as a formatted .xlsx workbook — dates, currency formatting, and totals already applied, ready for further analysis.
💼
One-click account statement
Print PDF Report and Export Excel Report buttons live right on the Analytic Account form — no wizard needed for a single account's full history.
💰
Profit & Loss summary and Budget Items
The per-account statement rolls transactions up into a Revenue → Gross Profit → Operating Income → Net Profit flow, and lists any linked Budget Items automatically when Budget Management is installed.

How it works

01
Open the wizard
Accounting ▸ Reporting ▸ Analytic Account Report.
02
Set your filters
Date range, analytic plans or accounts, company, and posted or all entries.
03
Print or export
Click Print PDF or Export XLSX — the file is generated on the spot.
04
Or skip the wizard entirely
Open any Analytic Account and use the buttons on the record itself for its complete, always up-to-date statement.
Requirements
Depends only on Odoo's standard base, analytic, and account apps, plus the xlsxwriter Python library that ships with Odoo by default. No other external dependency.
