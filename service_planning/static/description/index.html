FOL. 02  —  WHAT'S INCLUDED
Confirm the order, get the schedule
Confirming a Sale Order creates its Planning Schedule automatically — customer, products, and dates carried across, hours calculated from the date range. Cancel or delete the order and the schedule follows.
A Gantt built for the whole team
A dedicated Planning Gantt gives dispatchers a single, visual timeline of every assignment across resources — not buried inside each Sale Order. See it in FIG. 01 above.
Recurring assignments, real rules
Repeat daily, weekly, monthly, or yearly with a full RFC-style recurrence — specific weekdays, "third Tuesday" style monthly rules, an end date, or a fixed count of occurrences.
Multiple resources, one assignment
Attach any number of resources to a single schedule, with a status — Open, Cancelled, or Deleted — that stays in sync with the linked Sale Order's own state.
Two report wizards, two angles
The Employee Report filters by resource, Sale Order, and date range to show what someone worked on. The SO Execution Report filters by a single date, a period, or one order to show who's executing it — both generate on screen or print straight to PDF. See FIG. 03 below.
Catch what fell through
One click checks every open Sale Order line against its planning record and reports back missing or duplicate assignments — before they become a staffing gap or a double-booking.

FOL. 04  —  QUESTIONS
What happens to the schedule if the Sale Order is cancelled?
Its status flips to Cancelled automatically — it isn't deleted, so the history stays visible. If the order itself is deleted, the linked schedule is marked Deleted and unlinked from the order rather than removed outright.
How granular can a recurrence rule get?
Daily, weekly, monthly, or yearly, with an interval and a choice of ending — a repetition count, a specific end date, or ongoing. Weekly rules pick individual weekdays; monthly rules can target a date of the month or a pattern like "the last Friday."
Can one Sale Order have more than one planning entry?
By design, no — each order syncs to a single schedule that's updated as the order changes, and creating a duplicate for an already-planned order is blocked with a validation error. The Missing/Duplicate check surfaces anything that still slips through.
Which report wizard do I want?
Starting from "who was working" — use the Employee Report, filtered by resource, order, or date range. Starting from "what's happening with this order" — use the SO Execution Report, filtered by a single date, a period, or the order itself. Both can generate on screen or print directly to PDF.
