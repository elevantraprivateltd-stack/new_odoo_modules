Workflow

What actually happens, step by step

Nothing hidden — this is the exact path from an empty board to a printed report.

01

Open Planning Gantt

Switch between Day, Week, Month, and Year, or search by sale order.

02

Add an allocation

Click "+" on a day, or let a confirmed sale order create one automatically.

03

Fill it in

Sale order, assignment name, dates, allocated hours, resources — then Check Validation.

04

Track it

The same allocation shows up on Schedule Timeline's calendar view.

05

Report on it

Run an Employee Report filtered by sale order, date, or person, and print it to PDF.

Features

What's actually in the module

Planning Gantt

Day / Week / Month / Year

One board, four zoom levels, a search box scoped to sale orders, and a Publish action.

Automation

Manual or automatic

Add an allocation from the "+" on any day, or let a confirmed sale order create it for you.

Assignment

Resources & hours

Attach resources to the allocation and log allocated hours alongside start and end dates.

Recurrence

Recurrent toggle

Flag an allocation as recurring right from the same form, no separate setup screen.

Schedule Timeline

Calendar, list & kanban

The same allocations, viewed as a month calendar with a mini date picker alongside it.

Reporting

Employee Report

Filter by sale order, date range, or employee — every field optional — then print to PDF.

Open — the default status on a new allocation
Cancelled — set when the linked sale order is cancelled
Deleted — kept for record instead of being removed
