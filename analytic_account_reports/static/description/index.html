Analytic Account Reports

Print and export Analytic Account reports in PDF & XLSX

Overview

This module adds a reporting wizard and per-account print actions for Analytic Accounts in Odoo. Generate clean, professional PDF statements or export the same data to Excel, filtered by date range, analytic plan, analytic account, company, and posted/all entries.

Key Features

📅 Flexible Filters

Filter by Date From / Date To, Analytic Plans, one or more Analytic Accounts, Company, and Posted vs. All entries.

📄 PDF & Excel Export

One click to print a polished PDF report or export the same dataset to a formatted XLSX workbook.

📊 Per-Account Statement

Print or export a full statement — including a Profit & Loss summary and Budget Items — directly from any Analytic Account record.

How It Works

  1. Go to Accounting ▸ Reporting ▸ Analytic Account Report.
  2. Set your Date From / Date To, choose analytic plans or accounts, and pick posted or all entries.
  3. Click Print PDF or Export XLSX.
  4. Alternatively, open any Analytic Account record and use the Print PDF Report / Export Excel Report buttons for a complete, always-up-to-date statement of that single account.

Requirements

Depends only on Odoo's standard base, analytic and account apps, and the xlsxwriter Python library that ships with Odoo. No other external dependency.
