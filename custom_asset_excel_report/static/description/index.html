Module Overview

The Asset Excel Report module enhances Odoo 19 Community Edition by bringing interactive Excel (XLSX) reporting capabilities for Fixed Assets and Asset Disposals. Built to seamlessly integrate with accounting kits, it simplifies asset audits, depreciation tracking, and write-off reporting through custom filter wizards.

Key Features & Reports

Designed for fast, flexible, and detailed financial reporting.

Fixed Assets Excel Report

Export complete details of active assets, depreciation schedules, purchase values, and net values into clean Excel sheets.

Asset Disposal Report

Keep accurate accounting records of scrapped, retired, or sold assets with dedicated disposal reporting.

Filter Wizards

Filter report data easily by date ranges, asset categories, and states using interactive Odoo wizards before downloading.

Extended Asset Management

Custom views for disposal and asset management tailored specifically to work alongside base accounting modules.
