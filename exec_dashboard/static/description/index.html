Exec Dashboard

One-click executive dashboards built right into CRM, Sales, Invoicing & Project — no reports, no filters, just the numbers that matter.

Exec Dashboard adds a simple “Dashboard” menu inside the apps you already use. Every KPI is a clickable card — click any number and Odoo opens the exact filtered list behind it. No new app to learn, no separate screen to remember.
